README 简介

面向盲人出行辅助的桌面视觉导航原型。
将 YOLO、Depth Anything V2、盲道分割、GPS 和 TTS 串成可运行的实时感知链路。

这个项目不是单纯目标检测 Demo，而是围绕“感知 -> 决策 -> 播报 -> 导航”的完整流程来做。README 当前强调的核心点包括：

  • 多模型实时协同（YOLO + 深度估计 + 盲道分割）
  • 风险筛选播报（按距离、方向、盲道状态提醒）
  • 长期去重播报（减少重复语音）
  • 自由探索 / 路线导航 / 视频模拟三种模式
  • 支持 GPS 接入与训练工具链
